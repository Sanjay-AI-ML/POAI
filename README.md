## 🧪 Experiments Summary

| # | Experiment Name | File | Description |
|---|---|---|---|
| **1** | **A* Search Algorithm** | `A STAR SEARCH ALGORITHM` | Heuristic grid pathfinding using Manhattan distance $f(n) = g(n) + h(n)$ with priority queues. |
| **2** | **Blocks World Problem** | `BLOCKS WORLD PROGRAM` | Goal-driven classical planning system adhering to physical clear-block constraints. |
| **3** | **Depth First Search (DFS)** | `DEPTH FIRST SEARCH` | Recursive graph traversal for automated warehouse graph pathfinding. |
| **4** | **Forward Chaining** | `FORWARD CHAINING` | Data-driven deductive inference engine for diagnostic expert systems. |
| **5** | **Backward Chaining** | `IMPLEMENTATION OF BACKWARD CHAINING` | Goal-driven recursive reasoning verifying hypotheses from base facts. |
| **6** | **Fuzzy Inference System (FIS)** | `FUZZY INFERENCE SYSTEM` | Mamdani Fuzzy System with triangular membership functions using `scikit-fuzzy`. |
| **7** | **Minimax Algorithm** | `MINIMAX algorithm` | Adversarial zero-sum game player determining optimal moves in Tic-Tac-Toe. |
| **8** | **8-Queens Problem** | `Queen's Gambit Solution Algorithm.py` | Recursive backtracking search finding all 92 valid configurations on an $8 \times 8$ chessboard. |
| **9** | **Unification & Resolution** | `UNIFICATION AND RESOLUTION ALGORITHM` | Robinson's first-order logic unification and Modus Ponens Horn clause theorem prover. |
| **10** | **Prolog Logic Rules** | `prolog` | Declarative Prolog logic rules for computing the minimum and maximum of two numbers. |

## 🚀 Setup & Execution

### Prerequisites
- Python 3.10+
- `numpy`
- `scikit-fuzzy`

Install required dependencies:
```bash
pip install numpy scikit-fuzzy
```

### Running Individual Scripts
You can run any experiment directly via Python:
```bash
python "A STAR SEARCH ALGORITHM"
python "BLOCKS WORLD PROGRAM"
python "DEPTH FIRST SEARCH"
python "FORWARD CHAINING"
python "FUZZY INFERENCE SYSTEM"
python "IMPLEMENTATION OF BACKWARD CHAINING"
python "MINIMAX algorithm"
python "Queen's Gambit Solution Algorithm.py"
python "UNIFICATION AND RESOLUTION ALGORITHM"
```
